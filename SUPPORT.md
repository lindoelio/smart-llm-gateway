# Support

## Getting help

For installation, configuration, API usage, and development questions, start
with the [README](README.md) and the command-line help:

```sh
cargo run -p smart-llm-gateway -- --help
```

If the documentation does not answer the question, open a GitHub issue with a
clear title and a minimal, reproducible description. Please use the relevant
issue template when one is available.

## Before opening an issue

- Check existing issues for duplicates.
- Reproduce with the current source where possible.
- Include the operating system, Rust toolchain, command used, expected result,
  observed result, and sanitized error output.
- Reduce the report to the smallest useful configuration and request.

Never include access material, database URLs, private host names, customer
data, prompts, completions, or unredacted logs. For a security problem, follow
the private process in [SECURITY.md](SECURITY.md) instead.

## Community expectations

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md). Be
respectful, assume good intent, and keep discussions focused on making the
project more useful and reliable.

## Support boundaries

This is an open-source project. Support is provided on a best-effort basis;
there are no guaranteed response times, service-level commitments, or managed
hosting support. Do not use public channels for urgent security incidents or
production emergencies.
